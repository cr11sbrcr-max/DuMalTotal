# Para a Nicolly | De Cauã ❤️

Um site romântico, sincero, bem-humorado e inesquecível feito exclusivamente para a Nicolly.

## 🌟 O que está incluído no projeto:
- **Fotos Reais do Casal**: Já inclusas e pré-configuradas nativamente nos slots do site (`src/data/saved_photos.json`).
- **Música Oficial**: "Pixote - Mande Um Sinal (15 Anos - Ao Vivo)" configurada com player integrado.
- **Corações Caindo**: Animação suave e contínua de corações no fundo da tela do celular.
- **Layout Mobile & Desktop**: Enquadramento de smartphone interativo (com Dynamic Island) e modo expandido.
- **Fileiras de Duas Fotos**: Galeria otimizada em grade dupla (`grid-cols-2`).
- **Recursos Interativos**: Termômetro de saudade, cartas interativas, easter eggs e muito mais.

---

## 🚀 Como rodar localmente:

1. **Instalar dependências**:
   ```bash
   npm install
   ```

2. **Iniciar servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
   Ou apenas o Vite frontend estático:
   ```bash
   npm run dev:vite
   ```

3. **Gerar build de produção**:
   ```bash
   npm run build
   ```

---

## 🐙 Como enviar para o GitHub:

1. Inicie o repositório git:
   ```bash
   git init
   git add .
   git commit -m "Site romântico para Nicolly - versão completa"
   ```

2. Crie um repositório no seu GitHub e vincule:
   ```bash
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```

## 💜 Como importar no Lovable ou Vercel:

- **No Lovable**: Crie um novo projeto e selecione "Import from GitHub" (ou faça upload dos arquivos do projeto). O Lovable detecta automaticamente o template Vite + React + Tailwind CSS.
- **Na Vercel**: Conecte seu repositório do GitHub e clique em "Deploy". As fotos e a música funcionarão imediatamente!
